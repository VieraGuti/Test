## What VAST: Dead Zone changes

The current mobile/browser version is a substantial new implementation made for WebGL/Three.js and touch controls rather than a byte-for-byte Unity port. It preserves the survival-FPS direction (weapons, inventory/loot, player vitals, zombies and exploration) while adding mobile input, functional zombie state AI, a new environment, modern HUD, day/night simulation, weapon handling and browser deployment.

Original-project credit should remain visible in this file and/or the game credits as the project is developed further.
